## U-20260925-32 · 2026-09-25 · Two new audit tests failed CI: the window probe needs qt_material, which the headless jobs lack, and 3.14 on Linux and macOS parses JSON nested 50,000 deep · #testing #ci

- **Found by**: PR #489's `pytest-headless` jobs failed on 800898c2 and 4745ff8d, on every platform. Locally everything had passed.
- **`test_gui_tab_lifecycle_audit.py::test_destroying_the_window_removes_its_listeners`** (all jobs):
  - The probe imports the real main window, which styles itself with `qt_material`. The headless jobs do not install it (`ModuleNotFoundError: No module named 'qt_material'`).
  - The test now skips without it, as the other main-window tests already do.
- **`test_server_report_audit.py`, four tests** (Python 3.14 on Ubuntu and macOS):
  - On those builds the C JSON parser read all 50,000 levels of `[[[...]]]` without a `RecursionError`. The payload then parsed as a list, so the tests saw "body must be an object" (REST), `-32600` (MCP) or a parsed value (webhook, clients) instead of the handling under test.
  - How deep the parser goes first depends on the build and the stack. The tests now simulate it: a `too_deep` fixture makes `json.loads` raise `RecursionError` for that payload. What they check, that each server and client handles the error, is unchanged.
- **Files**: `test/unit_test/headless/{test_gui_tab_lifecycle_audit,test_server_report_audit}.py`.

## U-20260925-33 · 2026-09-25 · Integration helpers at their edges: secrets nested in arguments are masked, credentials stay behind on redirects, assert_http and config sync go through http_client, Office / S3 / SQLite errors stay in the framework family, the IMAP trigger fires once per message and names any mailbox, cassettes keep no credentials · #bugfix #security #integration

These findings come from an audit of the database, HTTP, notification, Office, S3, data-source and IMAP helpers, all reproduced with loopback servers and fakes. `test_integration_helpers_audit.py` (new, 19) fails 16 of its 18 runnable tests on the old code; the other 2 are guards, and the Office test skips without openpyxl.

- **Secrets nested in arguments**, high:
  - Masking by name applied to top-level arguments only. `{"smtp": {"password": ...}}` and `{"headers": {"Authorization": ...}}` reached the executor log and the run record's keys in plain text.
  - `redact_actions` now masks sensitive names at every depth. The credential headers (`Cookie`, `X-Api-Key`...) are among those names.
  - `AC_notify_webhook`'s `url`, a Slack, Discord or Teams key in itself, is masked too.
- **One list of credential headers**: `http_headers.CREDENTIAL_HEADERS`. `http_client` strips all of them on a redirect to another origin; before, `X-Api-Key` and `X-Auth-Token` were forwarded. The cassette uses the same list.
- **`http_client`**:
  - A 4xx/5xx body cut off mid-chunk raised `http.client.IncompleteRead`, which is no `OSError`, from inside the `except HTTPError` clause, and aborted the script. The error response is now read and closed in its own handler, and a malformed one becomes `URLError`.
  - A reply nested thousands deep raised `RecursionError` out of every `http_request`; `_try_json` now treats it as not JSON.
- **`assert_http`**: it called `urlopen` directly, bypassing the egress policy (a locked-down run still reached `/internal`), the redirect checks and the 64 MiB body cap. It now uses `build_call` / `perform_call`.
- **Config sync**: plain `urlopen` followed a redirect to any host with `X-Signaling-Secret` attached, and ignored the egress policy. It now goes through `http_client` without following redirects; a 3xx is a `ConfigSyncError`.
- **Office readers** (`read_workbook`, `read_document`, `read_presentation`): a file that is not the format raised `zipfile.BadZipFile` or python-docx's `PackageNotFoundError` and aborted the script. These are now `AutoControlActionException`.
- **S3 store**: botocore's `ClientError` escaped all four `AC_s3_*` commands. It is now `ArtifactStoreError(AutoControlException, RuntimeError)`.
- **SQLite data source**: `connect` sat outside the error handling, so a file that cannot be opened raised `sqlite3.OperationalError` past `AC_for_each_row`.
- **IMAP trigger**:
  - Two polls running together (the watcher and `AC_email_trigger_poll_once`) both fired the same message. A UID is now claimed atomically before it is fetched.
  - A UIDVALIDITY change now clears the seen UIDs, so a new message reusing an old UID is no longer skipped forever.
  - Mailbox names are sent in modified UTF-7 (RFC 3501 5.1.3). `已處理` raised `UnicodeEncodeError`, and `R&D` went out unencoded. Names already in that form are left alone.
- **Cassettes**: credential query parameters, JSON body members and response members are now masked, not only headers. Replay compares the masked forms, so recorded calls still match.
- **Tests**:
  - Three test helpers were updated: the `assert_http` tests patch `http_client`'s transport rather than `urlopen`, and three fake IMAP clients answer `response()` as imaplib does.
  - The 762 related tests pass.
- **Files**:
  - Code: `utils/{http_headers,executor/action_redaction,http_client/http_client,http_cassette/http_cassette,assertion/assertions,config_sync/client,office/office,artifact_store/s3_store,data_source/data_source,triggers/email_trigger}.py`.
