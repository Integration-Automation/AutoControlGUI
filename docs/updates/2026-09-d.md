## U-20260925-33 · 2026-09-25 · Integration helpers at their edges: secrets nested in arguments are masked, credentials stay behind on redirects, assert_http and config sync go through http_client, Office / S3 / SQLite errors stay in the framework family, the IMAP trigger fires once per message and names any mailbox, cassettes keep no credentials · #bugfix #security #integration

These findings come from an audit of the database, HTTP, notification, Office, S3, data-source and IMAP helpers, all reproduced with loopback servers and fakes. `test_integration_helpers_audit.py` (new, 19) fails 16 of its 18 runnable tests on the old code; the other 2 are guards, and the Office test skips without openpyxl.

- **Secrets nested in arguments**, high:
  - Masking by name applied to top-level arguments only. `{"smtp": {"password": ...}}` and `{"headers": {"Authorization": ...}}` reached the executor log and the run record's keys in plain text.
  - `redact_actions` now masks sensitive names at every depth. The credential headers (`Cookie`, `X-Api-Key`...) are among those names.
  - `AC_notify_webhook`'s `url`, a Slack, Discord or Teams key in itself, is masked too.
- **One list of credential headers**: `http_headers.CREDENTIAL_HEADERS`. `http_client` strips all of them on a redirect to another origin; before, `X-Api-Key` and `X-Auth-Token` were forwarded. The cassette uses the same list.
- **`http_client`**:
  - A 4xx/5xx body cut off mid-chunk raised `http.client.IncompleteRead`, which is no `OSError`, from inside the `except HTTPError` clause, and aborted the script. The error response is now read and closed in its own handler, and a malformed one becomes `URLError`.
  - A reply nested thousands deep raised `RecursionError` out of every `http_request`; `_try_json` now treats it as not JSON.
- **`assert_http`**: it called `urlopen` directly, bypassing the egress policy (a locked-down run still reached `/internal`), the redirect checks and the 64 MiB body cap. It now uses `build_call` / `perform_call`.
- **Config sync**: plain `urlopen` followed a redirect to any host with `X-Signaling-Secret` attached, and ignored the egress policy. It now goes through `http_client` without following redirects; a 3xx is a `ConfigSyncError`.
- **Office readers** (`read_workbook`, `read_document`, `read_presentation`): a file that is not the format raised `zipfile.BadZipFile` or python-docx's `PackageNotFoundError` and aborted the script. These are now `AutoControlActionException`.
- **S3 store**: botocore's `ClientError` escaped all four `AC_s3_*` commands. It is now `ArtifactStoreError(AutoControlException, RuntimeError)`.
- **SQLite data source**: `connect` sat outside the error handling, so a file that cannot be opened raised `sqlite3.OperationalError` past `AC_for_each_row`.
- **IMAP trigger**:
  - Two polls running together (the watcher and `AC_email_trigger_poll_once`) both fired the same message. A UID is now claimed atomically before it is fetched.
  - A UIDVALIDITY change now clears the seen UIDs, so a new message reusing an old UID is no longer skipped forever.
  - Mailbox names are sent in modified UTF-7 (RFC 3501 5.1.3). `已處理` raised `UnicodeEncodeError`, and `R&D` went out unencoded. Names already in that form are left alone.
- **Cassettes**: credential query parameters, JSON body members and response members are now masked, not only headers. Replay compares the masked forms, so recorded calls still match.
- **Tests**:
  - Three test helpers were updated: the `assert_http` tests patch `http_client`'s transport rather than `urlopen`, and three fake IMAP clients answer `response()` as imaplib does.
  - The 762 related tests pass.
- **Files**:
  - Code: `utils/{http_headers,executor/action_redaction,http_client/http_client,http_cassette/http_cassette,assertion/assertions,config_sync/client,office/office,artifact_store/s3_store,data_source/data_source,triggers/email_trigger}.py`.
  - Also `CHANGELOG.md` and `architecture_explore.md` (line counts).

## U-20260925-34 · 2026-09-25 · Window and OS helpers at their edges: file dialogs need the exact title and the front before typing, watchdog keys go to the popup, psutil and regex errors are framework errors, empty needles are refused, file drops use absolute paths, the Window Manager acts on the selected window; input paths Jeffrey_RPA runs are recorded, not changed · #bugfix #windows #gui

These findings come from an audit of window management and OS integration: 16 bugs, each reproduced with probes that faked every Win32 call that would act. `test_window_system_audit.py` (new, 13) fails 10 of its 12 runnable tests on the old code; one is a guard, and one needs Windows.

- **Held back while Jeffrey_RPA runs**: its webrunner batch and Discord bot were running (`webrunner.pid` alive), and the bot calls `post_key_to_window`, `focus_window` and `save`/`restore_window_layout`. Following the workspace rule for code a live batch runs, the fixes to those paths are recorded under `Progress.md`'s blocked keyboard/mouse item, with locations and fixes:
  - `post_key` typing a character three times;
  - focus, show and z-order calls reporting success when Windows refuses;
  - cloaked and zero-area windows being listed;
  - saved layouts drifting 7 px and shrinking on every restore, and tiles running under the taskbar;
  - `wait_for_window` sleeping past its timeout.

  macOS minimized windows that cannot be restored need a macOS run and got their own item.
- **File dialogs**, high:
  - The default driver matched "Open" / "Save As" as a substring and never focused the window. "How to reopen closed tabs - Google Chrome" was taken for the Open dialog, and the path and Enter were typed into whatever window was active.
  - It now waits for a window with exactly that title and brings it to the front (the new `WindowManageBackend.bring_to_front`, which confirms the window really became the foreground). Otherwise nothing is typed and the result is `handled: False`.
- **Watchdog key rules**, high: the key was pressed in the user's active window. The popup is now brought to the front first; if Windows refuses, the rule records an error instead. An infinite poll interval, which raised `OverflowError` in the guard thread, is now clamped.
- **Errors outside the family**, high:
  - MCP `ac_kill_process` let `psutil.AccessDenied` escape; it ended the stdio worker without a reply. It is now `AutoControlActionException`.
  - `wait_until_window_title` let `re.error` escape for a bad pattern; it is now `ValueError`.
- **Empty needles**: `""` is in every name, so `wait_until_process("")`, `wait_until_window_title("")` and `assert_process("")` succeeded at once. They are now refused.
- **File associations**: an unregistered extension answered with the Open With picker (`OpenWith.exe`); with `ASSOCF_INIT_IGNOREUNKNOWN` it is `None`, as documented.
- **File drops**: relative paths went into `CF_HDROP` as given, and the receiving program resolved them against its own working directory. Clipboard file lists and window drops now carry absolute paths.
- **Window Manager tab**: Focus and Close acted on the first window whose title contained the selected row's title, so closing `notes.txt - Notepad` closed the unsaved `*notes.txt - Notepad`. They now act on the row's window id. Its filter refresh was a single-shot timer with no context, so it fired after the tab was deleted and read the deleted filter box. It is now tied to the tab; the WebRTC panel's five single-shots had the same shape and are tied to it too.
- **Tests**: two tests pinned the old behaviour and were updated: the watchdog key test (now fronts the popup) and the Window Manager error test (acts by id). The 1,300 related tests pass, and the WebRTC panel's 292.
- **Files**:
  - Code: `wrapper/window_backends/base.py`, `utils/{file_dialog/file_dialog,watchdog/popup_watchdog,mcp_server/tools/_handlers_system,smart_waits/waits,assertion/assertions,file_assoc/file_assoc,clipboard_files/clipboard_files,file_drop/file_drop}.py`, `gui/window_tab.py`, `gui/remote_desktop/webrtc_panel.py`.
  - Docs: the v8/v9 feature docs (Eng/Zh), `Progress.md`, `CHANGELOG.md`, and `architecture_explore.md` (line counts).
