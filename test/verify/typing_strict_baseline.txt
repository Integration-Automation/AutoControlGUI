# Modules that predate the strict typing tier.
#
# `pyproject.toml` holds a `[[tool.mypy.overrides]]` block that turns on
# `disallow_untyped_defs` and `disallow_any_generics`. Every module of the
# package must be either matched by that block or named here -- so a module
# written from now on is strict by default, because it cannot be here.
#
# This is the package as it stood at v0.0.225, when the tier was introduced.
# Rules (enforced by `test_typing_modernization_contract.py`):
#   * The list may only shrink. Annotate a module, name it in the override
#     block, delete its line.
#   * A new module may not join it. Fix the types instead.
#   * A deleted or renamed module loses its line in the same change; a module
#     written later under the same name is new and therefore strict.
